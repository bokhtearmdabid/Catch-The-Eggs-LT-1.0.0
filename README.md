A visually engaging and feature-rich arcade-style egg catching game built using **C++** and the **OpenGL** graphics library.  
Catch eggs, avoid hazards, trigger power-ups, and chase high scores in a dynamic animated environment.

---

## 🎮 Gameplay Overview

Control a basket to catch falling eggs from animated chickens.  
Different egg types reward or penalize your score, while power-ups introduce strategic advantages.  
The game runs on a **60-second timer** with increasing difficulty and combo-based scoring.

---

## ✨ Features

### 🔹 Core Gameplay
- 🎯 **Interactive Menu System**  
  Main Menu → Play → Pause → Game Over  

- ⏸️ **Pause & Exit Controls**  
  - `P` → Pause anytime  
  - `ESC` → Exit game  

- 🥚 **Multiple Egg Types**
  - Normal Egg → `+1`
  - Blue Egg → `+5`
  - Golden Egg → `+10`
  - Poop → `-10`  

- 🧺 **Basket Control**
  - Arrow Keys  
  - Mouse (simultaneously supported)  

- ⏱️ **Live HUD**
  - Countdown timer  
  - Current score  
  - Best score  

---

### ⚡ Power-Ups

| Power-Up | Effect |
|----------|--------|
| 🟢 **WIDE** | Basket grows for 8 seconds |
| 🔵 **SLOW** | Eggs fall at 45% speed for 7 seconds |
| 🟡 **TIME** | Adds +12 seconds |
| 🩵 **WIND** | Applies drift to eggs for 5 seconds |

---

### 🌟 Bonus Features

- 🐔 **Two Chickens System**  
  Independent movement and egg spawning  

- 🎨 **Animated Chickens**
  - Wing flapping  
  - Body movement  
  - Detailed parts (eyes, beak, feet)

- 💥 **Particle Effects**
  - Color-based explosion on every catch  

- 🔥 **Combo System**
  - 5+ catches without miss → **Double points**

- 📈 **Progressive Difficulty**
  - Increasing spawn rate over time  

- 🌄 **Animated Background**
  - Scrolling clouds  
  - Gradient sky  
  - Bamboo poles  

- 📖 **Help Screen**
  - `H` → Open help  
  - `Backspace` → Return  

- 💨 **Wind Indicator**
  - Visual arrows shown during wind effect  

- ✨ **Basket Effects**
  - Green glow → Wide  
  - Blue glow → Slow
